# Конспект: Промпт-інженерія

Промпт-інженерія — це мистецтво складання запитів до AI-моделі, щоб отримати якісну та передбачувану відповідь.

## Основні техніки:

1. **Системний промпт (System Prompt).** Визначає роль моделі та правила. Наприклад: "Ти — аналітик відгуків. Відповідай ТІЛЬКИ у форматі JSON."

2. **Few-shot навчання.** Даємо моделі приклади вхідних даних та бажаних відповідей. Модель наслідує формат.

3. **Temperature (температура).** Керує творчістю:
   - 0.0 = максимальна точність, мінімум творчості
   - 0.7 = збалансовано
   - 1.0 = максимальна творчість

4. **Chain of Thought.** Просимо модель мислити по кроках: "Спочатку поясни, потім дай відповідь."

5. **Structured Output.** Вимагаємо строгий формат (JSON, XML) для машинної обробки.

## Помилки промпт-інженерії:

- Забути вказати формат відповіді
- Дати забагато правил одночасно
- Не перевіряти відповіді на валідність
- Використовувати занадто високу temperature для структурованих даних
